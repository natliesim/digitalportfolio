# Natalie Sim — Digital Portfolio

A one-page portfolio: Work, School, Personal, About and Toolkit tiles that open into project panels, plus a CV download.

- `index.html` — the whole site. Project content lives in the `SECTIONS` object near the top of the `<script>`; edit titles, descriptions, tools and GitHub links there.
- `assets/NatalieSim_CV2026.pdf` — the CV behind the "Download CV" button.

To host it for free, turn on GitHub Pages (Settings → Pages → deploy from branch, root folder).
